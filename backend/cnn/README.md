# Animals Image Classification

CNN model untuk klasifikasi 5 jenis hewan menggunakan TensorFlow/Keras.

## Dataset
- Source: Kaggle - antobenedetti/animals
- Total: ~15.000 gambar
- Classes: cat, dog, elephant, horse, lion

## Model Architecture
Sequential CNN dengan 5 Conv Block + Dense layers

## Results
- Train Accuracy: 97.85%
- Test Accuracy: 94.25%

## Model Formats
- SavedModel
- TF-Lite
- TFJS
